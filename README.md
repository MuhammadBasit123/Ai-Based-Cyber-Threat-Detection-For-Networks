# Ai-Based-Cyber-Threat-Detection-For-Networks
Explainable AI-based Network Intrusion Detection System trained on CIC-IDS2017. Combines Random Forest, XGBoost, and an LSTM-Autoencoder for known and zero-day threat detection, featuring SHAP explanations, MITRE ATT&amp;CK mapping, live Scapy packet-to-flow capture, FastAPI, PostgreSQL, and a React dashboard with automated response.
